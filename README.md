# Fashion Ecommerce Dashboard

## 개요
이 대시보드는 패션 이커머스 데이터를 시각화하여 브랜드별 월별 사용자 추이 및 연간 점유율을 분석합니다.

## 실행 방법

1. **필수 라이브러리 설치**
   ```bash
   pip install -r requirements.txt
   ```

2. **애플리케이션 실행**
   ```bash
   streamlit run app.py
   ```

## 데이터 형식 가이드
업로드하는 엑셀/CSV 파일은 다음 규칙을 따라야 합니다:
- **헤더 위치**: 2번째 행 (Row Index 1) 권장 (자동 감지 기능 포함)
- **컬럼 구조**:
  - 첫 번째 컬럼: `Mall` (쇼핑몰 이름)
  - 이후 컬럼: `1월`, `2월`, ... (월별 숫자 데이터)
- **데이터 처리**: 콤마(,)가 포함된 숫자는 자동으로 정수로 변환되며, 결측치가 있는 행은 제외됩니다.
